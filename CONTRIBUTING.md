# Contributing

Small, reproducible contributions are welcome.

1. Open an issue describing the problem and a minimal HTML fixture.
2. Make a focused change and add a regression check in tests/run.php.
3. Run php tests/run.php and include results in the pull request.

Never include secrets or private customer data. Test only authorized systems. Favor deterministic offline tests; live requests must be opt-in.

## First contribution

Browse [open issues](https://github.com/Hamzaaqq/openqa-toolkit/issues) and check whether someone is already working on the task. Start with a small fixture, test, or documentation improvement. Explain what you verified, disclose any AI assistance when relevant, and be prepared to maintain your contribution. Do not submit duplicate or cosmetic changes just to increase contribution counts.

To report a bug, include PHP version, operating system, a minimal reproducible command and expected versus actual behavior.
