# Try OpenQA and share feedback

OpenQA is an early-stage MIT-licensed PHP QA toolkit. Start with the offline tutorial; it takes about five minutes and requires no website access.

We especially welcome reports from developers using Windows, Laravel Blade, or static site builds. Tell us your environment, what you tried, and expected versus actual behavior. Please do not share sensitive data.

- Tutorial: [first audit](tutorial.md)
- Laravel: [integration guide](laravel.md)
- CI: [GitHub Action guide](github-action.md)
- Feedback and contributions: https://github.com/Hamzaaqq/openqa-toolkit/issues

Maintainers should share the project only in relevant communities where self-promotion is allowed, disclose their relationship to it, and request practical feedback instead of stars or artificial activity.
