What it checks

Small, focused, actionable.

01 / HTML

Document quality

Spot missing titles, language declarations and image alt attributes, duplicate IDs and unresolved local anchors.

02 / HTTP

Response review

On authorized targets, inspect HTTP status, request timing and advisory security headers using one GET request.

03 / CI

Repeatable reports

Use JSON output, documented exit codes, Laravel integration and a reusable GitHub composite action.

Start here

Your first audit.

Install PHP with DOM and cURL. Try the included fixture without accessing a live website.

Read the full installation guide →
git clone https://github.com/Hamzaaqq/openqa-toolkit.git
cd openqa-toolkit
php bin/openqa html examples/sample.html --json

Know the limits.

OpenQA is an early-stage heuristic checker, not a full accessibility or security audit. It does not execute JavaScript, crawl sites or verify external links. Only audit systems you own or have permission to test.
