Quick start

From installation to your first reproducible audit.

RequirementsInstallFirst auditHTTP modeExit codes

Requirements

PHP 8.2 or later, DOM and cURL extensions. Composer is optional for the standalone checkout.

php -v
php -m

Install

Composer

Use the published package in a development project. If indexing is not complete, use the Git checkout below.

composer require --dev hamzaaqq/openqa-toolkit:^0.1
vendor/bin/openqa --version

Windows Command Prompt:

vendor\bin\openqa.bat --version

Git checkout

git clone https://github.com/Hamzaaqq/openqa-toolkit.git
cd openqa-toolkit
php bin/openqa --version

First audit: offline exercise

php bin/openqa html examples/sample.html --json

Expect three intentional findings: a missing image alt attribute, duplicate ID and missing local anchor. Copy the fixture to a scratch file, fix each finding, and audit it again. Expect zero findings. Use meaningful alt text or empty alt for decorative images.

Authorized HTTP checks

Only use this mode with permission. Replace the example URL with your authorized target.

php bin/openqa url https://example.com --authorized --json

One GET request, no redirects, 15-second timeout, 2 MiB response limit. HTML checks run on successful HTML responses. Missing CSP, Referrer-Policy, X-Content-Type-Options and HTTPS HSTS are advisory findings. Timing is not browser performance.

Never expose the URL checker as a public service; it can reach local or private networks.

Interpret exit codes

OpenQA exit codes
CodeMeaning
0No findings
1Findings require review
2Usage or operational error

In PowerShell check $LASTEXITCODE. Findings do not establish accessibility compliance or security vulnerabilities.
