Contribution workflow

  1. Check existing issues for duplicate work.
  2. Fork and create a focused branch.
  3. Add a reproducible fixture or test.
  4. Run the checks and report actual results.
  5. Open a pull request and respond to feedback.
php tests/run.php
# For Laravel integration tests:
composer update
vendor/bin/phpunit --bootstrap vendor/autoload.php tests/Laravel

Report responsibly.

Include PHP and OS versions, a minimal command, expected behavior, and actual output. Remove credentials and personal data. For security issues use the security reporting guide. Disclose relevant AI assistance; do not create artificial activity.
